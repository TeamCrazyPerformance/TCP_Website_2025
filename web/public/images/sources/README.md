# 소스 아이콘

`{sourceId}.png` 형식으로 두면 공개 목록의 소스 선택기가 자동으로 씁니다.
파일이 없으면 이름 첫 글자로 만든 표식으로 떨어지므로, 새 소스를 추가하면서
이미지를 넣지 않아도 화면은 깨지지 않습니다.

예) `infoq.png`, `cloudflare-blog.png`, `sdtimes.png`, `github-trending.png`

## 왜 외부 파비콘 서비스를 쓰지 않나

`google.com/s2/favicons` 같은 서비스를 쓰면 **방문자 브라우저가 그 서비스에
직접 요청**합니다. 이용자 IP 와 "지금 어떤 소스를 보고 있는지"가 제3자로
전송되는 셈입니다.

`docs/PRIVACY_DRAFT.md` 는 "외부 분석/로그 전송은 하지 않는다"고 밝히고 있고,
Cloudflare 한 곳을 위해 국외이전 고지를 따로 두고 있습니다. 아이콘 하나 때문에
같은 고지를 또 만들 값어치는 없다고 판단했습니다.

## 이미지를 넣을 때

- 20×20 으로 표시되므로 **40×40 이상** 정사각 PNG 를 권합니다.
- 각 소스의 공식 파비콘이나 로고를 **변형 없이** 씁니다. 출처를 식별하기 위한
  용도라 크기를 줄여 이름 옆에 두는 선에서만 사용합니다.
- 라이선스가 불분명하거나 사용을 제한하는 소스는 **파일을 넣지 마세요.**
  표식으로 떨어지며, 그래도 도메인이 함께 보이므로 구분에는 지장이 없습니다.
